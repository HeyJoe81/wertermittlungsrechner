# Wertermittlungsrechner

Rechner für Vergleichs-, Sach- und Ertragswert nach ImmoWertV 2021, mit Basisdaten für Stuttgart und Umgebung.

**Aufrufen:** https://heyjoe81.github.io/wertermittlungsrechner/

Auf dem Handy: Seite öffnen, dann „Teilen → Zum Home-Bildschirm“ (iPhone) bzw. „Zum Startbildschirm hinzufügen“ (Android). Nach dem ersten Aufruf funktioniert der Rechner auch offline. Eingaben bleiben nur im eigenen Browser gespeichert.

Hinweis: Hilfsmittel zur Orientierung, kein Verkehrswertgutachten.
